# Pages Directory

This directory contains the pages for your Astro site. Each `.astro` file in this directory becomes a page on your site.

## Customising `index.astro`

The file `src/pages/index.astro` is included by default and serves as the template’s homepage. Feel free to edit or replace it with your own design.

There are no route conflicts to worry about—this starter no longer ships with a bundled documentation site. All docs are hosted separately, so `/` is yours to control from day one.
