This project uses a collection of custom scripts to automate common tasks, enforce quality standards, and enhance the build process. This page provides an overview of what each script does.

## Package Scripts

These scripts are run from the command line using `pnpm run <command>`.

| Command | Script | Description |
| :--- | :--- | :--- |
| `build:tokens` | `scripts/src/build-tokens.ts` | Compiles design tokens from `/tokens` into CSS variables and a Tailwind theme. |
| `check:budgets` | `scripts/src/track-performance-budgets.ts` | Checks the site's performance metrics against defined budgets. |
| `validate:contrast` | `scripts/src/validate-contrast.ts` | Checks design token color combinations for WCAG AA contrast compliance. |
| `validate:overrides` | `scripts/src/validate-budget-overrides.ts` | Validates the structure of the `budget-overrides.json` file. |
| `audit:ci` | `scripts/src/audit-filter.ts` | Runs `pnpm audit` and filters the output for use in CI. |
| `baseline:performance` | `scripts/src/baseline-performance.ts` | Tracks baseline performance metrics for comparison. |

## Build-Integrated Scripts

These scripts are plugins that run automatically during the `astro build` and `astro dev` processes. They are configured in `astro.config.mjs`.

| Type | Script | Description |
| :--- | :--- | :--- |
| Remark | `remark-base-prefix.mjs` | Automatically adds the site's `base` path to internal links. |
| Remark | `remark-snippet-includes.mjs` | Allows embedding code snippets from files into Markdown. |
| Remark | `remark-validate-links.mjs` | Validates all internal links in non-documentation Markdown files. |
| Vite | `vite-plugin-inject-versions.mjs` | Makes version numbers from `versions.json` available in documentation pages. |
