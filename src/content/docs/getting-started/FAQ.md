## Getting Started

### Where did the documentation site go?

You’ll notice the starter now opens with a normal `index.astro` homepage. The full Starlight docs have moved to their own domain (`https://aps.docs.clownware.org`). A trimmed-down copy of the docs lives locally in `/docs` purely for AI assistants and reference.
