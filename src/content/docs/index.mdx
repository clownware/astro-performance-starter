## 🛠️ Tech Stack Highlights

**Modern tools with excellent developer experience:**

- **Framework**: Astro v{{versions.astro}} with Vite v{{versions.vite}} bundler
- **Styling**: Tailwind CSS v{{versions.tailwindcss}} + Design tokens system
- **Structured Interactivity**: Preact v{{versions.preact}} — Performant interactive islands
- **Code Quality**: Biome v{{versions.biome}} (20x faster than ESLint + Prettier)
- **TypeScript**: v{{versions.typescript}} in strict mode with path aliases
- **Content Collections & Type-Safety**: Astro Content Collections with Zod schemas
- **Commit Message Linting**: Commitlint is integrated with Husky for semantic versioning
- **Link Validation**: Automated checking for all internal links (+docs) via custom Remark plugin.
- **Package Manager**: pnpm v{{versions.pnpm}} (required for performance)
- **Comprehensive Testing**: Playwright v{{versions.playwright}} for E2E tests + Vitest for fast unit tests
- **Performance Automation**: Sharp v{{versions.sharp}} image optimization + Lighthouse CI
