Two years driving out things that didn't need to be there. Carousels nobody
scrolled. Analytics scripts that fired before the page rendered. Animations on
elements the user couldn't see. By the end of every gig the site weighed less
and did the same work.

## What I learned haunting other people's bundles

- **Most JavaScript is regret.** Someone meant well; the user paid the cost.
- **The fastest spinner is the one that never loads.** If the content can be
  static, make it static.
- **Performance budgets are exorcisms.** If a number doesn't fit in the budget,
  something has to leave the page. The number wins.
