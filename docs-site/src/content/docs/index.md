## Tech Stack

- **Framework**: Astro v5.x with Vite 6.x bundler
- **Package Manager**: pnpm 9.x (required)
- **Runtime**: Node.js 20.x LTS
- **Styling**: Tailwind CSS v4.0-beta with design tokens
- **Code Quality**: Biome (20x faster than ESLint + Prettier)
- **Content**: MDX with Astro Content Collections API
- **Images**: Astro Image component with Sharp processing
