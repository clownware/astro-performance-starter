04 — Iconography · Lucide (no bespoke set)

Standardize on Lucide via astro-icon

Lucide’s geometric 24/2px grid and rounded joins echo Space Grotesk’s mechanical-but-soft terminals — a clean pairing. Shipped build-time through the existing Icon.astro, zero runtime JS. We define conventions, not a new set.

Contrast. Default icon color = foreground-secondary → 5.68:1 light · 7.48:1 dark on background (passes ≥ 3:1 for non-text graphics with margin). Wordmark = foreground-primary → 16.5:1 / 18.2:1. Gradient marks are decorative; the mono fallback carries any meaning-bearing use.
Deliverables. Signature spark (gradient + mono), wordmark lockups (3 variants), and favicon (16/32 + app tile) — all SVG, light + dark, at favicon / inline / hero sizes. Standalone assets saved to brand/. Iconography is Lucide via astro-icon with the sizing/stroke/color spec above — no bespoke icon set.
