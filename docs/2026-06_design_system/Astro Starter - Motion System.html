Page transitions — cross-document morph

Zero-JS MPA path. A document-level @view-transition makes the browser cross-fade the whole page on same-origin navigation — no router, no hydration. The live frame below is two real pages.

live · click “Go to scale →” inside the frame (Chrome 126+)
/* in the document <head> — both pages */
@view-transition { navigation: auto; }

/* tune the morph with tokens */
::view-transition-group(*) {
  animation-duration: var(--dur-slow);   /* 420ms */
  animation-timing-function: var(--ease-inout);
}

04

Animated conic glow border

Reuses the registered @property <angle> trick from AnimatedGradientText. A conic gradient rotates around a masked 1.5px ring — the only decorative loop in the system, reserved for one featured item per view.

Featured

Edge runtime

One rotating conic gradient, masked to the border. Animating a registered custom property stays off the main thread.

@property --glow-ang {
  syntax: '<angle>'; inherits: false; initial-value: 0deg;
}
.glow::before {                /* masked ring */
  background: conic-gradient(from var(--glow-ang),
              hsl(var(--g1)), hsl(var(--g2)), hsl(var(--g1)));
  animation: spin 6s linear infinite;
}
@keyframes spin { to { --glow-ang: 360deg; } }

07

Cursor spotlight

Optional island · the only JS

A radial glow that tracks the pointer on the hero only. The island is ~12 lines: one pointermove listener writing two CSS vars, rAF-throttled. This is the entire JS motion budget — nothing else hydrates.

move your cursor → Hover the hero 
/* CSS does the rendering; JS only feeds 2 vars */
.hero::before { background:
  radial-gradient(280px circle at var(--mx) var(--my),
    hsl(var(--g1)/.3), transparent 66%); }

/* island.js — load: client:idle */
let q; el.addEventListener('pointermove', e => {
  if(q) return; q = requestAnimationFrame(() => {
    el.style.setProperty('--mx', e.offsetX+'px');
    el.style.setProperty('--my', e.offsetY+'px'); q=0; }); });
Compositor-onlyPaint: 1 gradientJS: 1 island (~0.4KB)
loadclient:idle — never blocks paint
throttlerequestAnimationFrame
No-JS / reduced-motion fallback: the island never mounts; --mx/--my stay at 50% 50% so a soft static centered glow renders. Nothing is lost, nothing moves.
Motion budget, summed. Six of seven techniques are 100% CSS, compositor-only, and gated behind prefers-reduced-motion. One optional island (cursor spotlight, ~0.4KB, client:idle) is the entire JavaScript surface. Decorative loops are capped: one conic border + two slow sheens, all pausable. Durations and easings map 1:1 to motion.duration / motion.ease in base.json.
